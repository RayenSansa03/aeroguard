# Security Policy

## Supported versions
Only the latest release of AeroGuard receives security fixes.

## Reporting a vulnerability
Please do not open a public issue. Use GitHub's private
"Report a vulnerability" button in the Security tab of this repository.
You will get an answer within 7 days.

## Automated checks
- Dependencies are audited with pip-audit on every pull request.
- Dependabot opens weekly update pull requests.
- CodeQL scans the code for security issues.
